Smart Slip

Open app

Add this page to your Home Screen so you get the gold SS icon. Then tap Open app.

iPhone — tap by tap

  1. You must be in Safari. If this opened inside Messages, Grok, or Chrome, tap the Safari / compass icon and choose Open in Safari.
  2. Tap the Share button (square with an up arrow).
  3. Scroll the list and tap Add to Home Screen. If you don’t see it, tap Edit Actions and turn it on.
  4. Leave the name as Smart Slip. Keep Open as Web App on.
  5. The preview icon should be the gold SS, not a black tile with the letter S. Then tap Add.
  6. If you already saved the letter-S icon, delete that shortcut first, then do these steps again.

Android — tap by tap

  1. Open this page in Chrome.
  2. Tap the ⋮ menu in the top right.
  3. Tap Add to Home screen or Install app.
  4. Tap Add / Install.
